# [DRAFT] ร่างสรุปกติกาเปิดระบบ Sprint 2 (เขียนขึ้นแบบเร่งด่วน — มีจุดผิดจากนโยบายจริง!)

> **หมายเหตุ:** เอกสารร่างนี้เขียนขึ้นจากความจำโดยยังไม่ได้ตรวจเทียบกับ `docs/policies/finance-and-sla-policy.md` ใช้สำหรับทดสอบการรีวิวด้วย Custom Agent `release-auditor` ใน **Lab 4.1**

> **ผู้ร่าง:** “จำได้ประมาณนี้ครับ ตอนประชุมจดครบทุกอย่าง ยกเว้นตัวเลข”
>
> **สถานะเอกสาร:** รอตรวจทาน — ผู้ร่างกดส่งแล้วปิดแจ้งเตือนเพื่อให้ทีมมีสมาธิในการรีวิว

## 1. กติกาการจองร้านอาหาร (`Project หมูกระทะ` · `CR-201`)
- **เงินมัดจำ:** เก็บเงินมัดจำ **`200 บาท` เท่ากันทุกโต๊ะ** ไม่ว่าจะมากี่ท่านก็ตาม (รวมถึงมา 1–2 ท่านก็ต้องจ่าย 200 บาท)
- **จำนวนลูกค้าสูงสุด:** จองผ่านหน้าเว็บได้สูงสุดถึง **50 ท่าน** โดยไม่ต้องกรอกช่อง `Notes`
- **เวลาชำระมัดจำและการคืนเงิน:** ชำระภายใน **24 ชั่วโมง** หลังกดจอง และ **ไม่คืนเงินมัดจำทุกกรณี** แม้จะแจ้งยกเลิกล่วงหน้าเกิน 24 ชั่วโมง

## 2. กติกาแคมเปญ 11.11 ร้านค้าออนไลน์ (`Project ชานมหวานร้อย` · `CR-202`)
- **โค้ดส่วนลด `SWEET11`:** ใช้ลดเพิ่ม **10% ได้กับสินค้าทุกชิ้นในร้าน** รวมถึงโซฟา `Lolito` ที่ลด `-50%` อยู่แล้วก็สามารถลดซ้อนทับได้
- **จำนวนสินค้าต่อคำสั่งซื้อ:** ลูกค้ากดสั่งซื้อได้สูงสุด **99 ชิ้น** ต่อรายการ
- **ข้อความบนหน้าจอ:** ใช้ป้ายกำกับตัวเรียงลำดับว่า **`"Short by"`** ตามเดิม ไม่ต้องแก้ไข
